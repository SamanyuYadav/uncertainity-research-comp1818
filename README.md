# Neural Network Confidence Under Image Corruption

This is the implementation used for the report: a NumPy 64-64-10 neural
network, MC Dropout, clean and mixed temperature scaling, simple baselines,
and evaluation on clean, noisy and blurred handwritten digits.

## Start here

1. Extract this ZIP and open the uncertainty_project folder.
2. Use Python 3.12 in a virtual environment.
3. Install dependencies:

       python -m pip install -r requirements.txt

4. Check the supplied data and trained model:

       python verify.py

5. Recreate the results tables, bootstrap comparisons and graphs:

       python analyse.py
       python large_figures.py

6. To train all models again and rerun the experiment:

       python run.py
       python verify.py
       python analyse.py
       python large_figures.py

run.py replaces data.npz and the saved results in this extracted folder.
Keep a copy if you want to retain the original outputs for comparison.
No GPU is required. The dataset is bundled with scikit-learn and a copy is
included as data.npz; no separate dataset download is needed.
For predictable CPU execution, you can set OPENBLAS_NUM_THREADS=1 before
starting Python. run.py also sets this if the variable is not already set.

## What is included

- run.py: model, Adam training, dropout tuning, calibration and evaluation.
- verify.py: data partition, gradient, metric, probability and checkpoint checks.
- analyse.py: aggregate scores, paired bootstrap and original landscape graphs.
- large_figures.py: the larger stacked graphs used in the revised report.
- make_demo.py and demo.html: generate or open the offline interactive demo.
- requirements.txt: versions from the original experiment.
- data.npz: all 1,797 images, digit labels and the four split-index arrays.
- DATASET_SOURCE.txt: the dataset description and attribution.
- results/model_0.npz to model_4.npz: the five trained neural networks.
- results/config.json: selected dropout, temperatures, training settings and versions.
- results/metrics.csv: all measured per-run and baseline results.
- results/summary.csv and bootstrap.csv: summaries and comparison intervals.
- results/predictions: all 150 saved probability arrays needed for analysis.
- results/*.png: graphs from the experiment.
- MANIFEST.json: SHA-256 checksums for the package files.

## Useful details

Load the data with numpy.load('data.npz'). The keys are x, y, train, tune,
cal and test. x contains 64 normalised pixels per image, and y contains labels.
The training, tuning, calibration and test groups contain 1078, 179, 180 and
360 images respectively.

A checkpoint stores arr_0, arr_1, arr_2 and arr_3 (weights and biases) and dropout.
verify.py demonstrates how to load a checkpoint and replay saved predictions.

Results to expect (five-seed means, rounded):
- Clean MC Dropout accuracy: 97.83%.
- Strong-noise MC Dropout accuracy: 66.56%.
- Strong-noise NLL: raw MC 1.184, clean scaling 1.474, mixed scaling 1.245.

The extension improves over clean-only scaling under strong noise, but does not
consistently outperform raw MC. Logistic regression performs better on severe
noise. The code reports these outcomes without selecting only favourable results.
Minor floating-point differences across software versions/platforms are possible.
